# M-vance factory bank (Kris 2 Nov, B1): 64 programs picked from three JP-8000/8080 banks for a broad selection, each
# renamed and with one value changed. Built by tools/make_bank.py into build/mvance-factory.syx and, through
# tools/mid2bank (the firmware's own SysEx parser and range clamp), firmware/gen/mv_factory.h.
#
#   source <letter> <file>            a bank: a .mid or .syx of JP-8000/8080 DT1 messages
#   <slot> <from> "<name>" <edit> ... # where it came from
#     slot   1..64, the program number on the FM-1
#     from   A:24  user patch 24 of source A (1..128, as the JP numbers them: A11 = 1 .. B88 = 128)
#            D:P26A  performance 26's upper patch (P26B: its lower)
#     name   up to 16 characters (ASCII 32..125); the two letters in front say what it is:
#            LD lead, PD pad, BS bass, PL pluck, AR arp, BR brass, ST strings, BL bell / keys, FX effect
#     edit   KEY=value (the stored byte) or KEY+n / KEY-n; KEY as in tools/mvance-params.yaml (CUTOFF, RESO,
#            FENV_D, AENV_R, DLY_LEVEL, MFX_LEVEL, PORTA_TIME, LFO1_RATE ...). Signed values are stored with
#            their centre (64 = 0), as the JP stores them. L.KEY=value edits the LOWER patch
#   performances (Kris 3 Nov, layer / split): every program is one; these lines say how it plays
#     D:P26           a whole performance of the source: its upper and lower patch, KEY MODE, SPLIT and BALANCE
#     LOWER=A:19      the LOWER patch (else a copy of the upper: a single)
#     MODE=SINGLE|DUAL|SPLIT  SPLIT=60 (notes below it LOWER)  BAL=64 (0..127, 64 both full)
#     e.g.  60  A:34  "LD Split Demo"  LOWER=A:19 MODE=SPLIT SPLIT=60
#   LFO1 SYNC (Kris 5 Nov): a performance's patch (D:P26, D:P26A, LOWER=D:P26B) brings its JP part's LFO1 SYNC with
#   it; SYNC= (upper) / L.SYNC= (lower) set it: OFF 1/16 1/8T 1/16D 1/8 1/4T 1/8D 1/4 1/2T 1/4D 1/2 1/1T 1/2D 1/1
#   2/1T 1/1D 2/1 3M 4M 5M 6M 7M 8M (or 0..22; D dotted, nM n measures). Synced, LFO1 RATE is not used.
#   DELAY SYNC / CHORUS SYNC RATE (Kris 7 Nov): the same, from the JP part's offsets 4 / 6; DSYNC= L.DSYNC= take
#   OFF .. 1/2 (0..10), CSYNC= L.CSYNC= the LFO1 list or LFO1 (0..23). The FX play UPPER's (DSYNC=, CSYNC=);
#   synced, the delay's TIME and the Multi-FX type's own rate are not used.
#
# The sources are third-party banks: see LICENSING.md before publishing a build with this bank.
